# プロダクト名

ウォッチカレンダー（仮）

## 概要

カレンダーとタイマー機能を組み合わせたウェブサイト。進捗の振り返りやどのくらい作業をしてどのくらい進捗が進んだのかを見やすくするためのWebサイトです。
機能は、既存のカレンダーの使い方のほかにタイマー機能があり行う作業を選んだ後にタイマーを起動させる。タイマーを止めると作業した時間帯がカレンダーに載る。ほかにも現在の進捗を見れたり、フレンドのユーザーのカレンダーや進捗を見ることができる。既存のモノでは予定をカレンダーに記入してみるだけであるがこれは、実際にやった内容と時間を記入できるため作業の進捗を見やすくできる。
