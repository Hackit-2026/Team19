# タイムライン - ストップウォッチ×カレンダー (PC版プロトタイプ)

ストップウォッチで計測した時間を、0:00〜23:30の30分刻みタイムラインに自動で記録するデスクトップアプリです。
タイマーを使わずに後から手動で追加したり、記録を編集・削除したりもできます。

## 必要なもの

- Python 3.8以降
- 追加インストール不要(tkinter は Windows/Mac 標準の Python に同梱されています)
  - Windows: python.org からインストーラーで入れた Python ならそのまま使えます
  - Mac: python.org 版 Python を推奨(Homebrew版は `brew install python-tk` が別途必要な場合があります)
  - Linux: `sudo apt install python3-tk` などが必要な場合があります

## 起動方法

```bash
cd timeline_app
python3 app.py
```

(Windowsでは `python app.py` でも可)

起動すると同じフォルダに `timeline.db` という記録用データベースファイルが自動で作られます。
このファイルを削除すると記録は消えるので、バックアップしたい場合はこのファイルをコピーしてください。

## 使い方

### 1. タイマーで記録する
「▶ タイマー開始」ボタンを押すとタイマー画面が開きます。

- 内容欄は「勉強・筋トレ・作業・読書」から選ぶことも、直接好きな文字を入力することもできます
  (ドロップダウンの▼から選ぶか、そのまま自由にタイピングしてください)
- 「開始」を押すと計測スタート、経過時間が表示されます
- 「停止」を押すと、開始〜終了の時間が自動でその日のタイムラインに記録されます

### 2. タイムラインを見る
メイン画面には 0:00〜23:30 の30分刻みの表が並びます。記録がある枠は水色でハイライトされ、
今日の現在時刻の枠は黄色でハイライトされます。

上部の「◀ 前日 / 翌日 ▶ / 今日」ボタンや日付欄への直接入力で、他の日の記録も見られます。

### 2-1. 1週間まとめて見る(週表示)
上部の「週表示」ボタンを押すと、月曜〜日曜の1週間分をまとめてグリッド表示できます。
「◀ 前週 / 翌週 ▶」で週を移動、日付欄への直接入力(例: 2026-08-03)でもその日を含む週に移動します。
セルをクリックするとその日・その時間帯の記録一覧(編集・削除・追加)が開き、
曜日の見出しをクリックするとその日の日表示に切り替わります。「日表示」ボタンでいつでも1日表示に戻れます。

### 3. 後から編集・削除する
タイムラインの行(時間帯)をクリックすると、その時間帯の記録一覧が表示されます。
各記録の「編集」から内容や時刻を修正、「削除」から記録を消せます。

### 4. タイマーを使わず手動で追加する
「＋ 手動追加」ボタン、またはタイムラインの行から「＋ この時間帯に追加」を押すと、
内容と時間帯(開始・終了)を選んで記録を追加できます。

日付欄も編集できるので、今表示している日以外(未来の予定や過去の記録)にも追加できます。
◀▶ボタンで前後の日に移動したり、「今日」ボタンで今日の日付に戻したりできます。
追加すると、その日付のタイムラインに自動で移動して結果を確認できます。

## データ構造(参考)

すべての記録は `timeline.db` (SQLite) の `activities` テーブルに1件ずつ保存されます。

| カラム | 内容 |
|---|---|
| day | 日付 (YYYY-MM-DD) |
| start_time / end_time | 開始・終了時刻 (HH:MM) |
| task | やったこと |
| seconds | 実際にかかった秒数 |
| source | 'timer'(タイマー計測) か 'manual'(手動追加) |

30分刻みのタイムライン表示は、このstart_time/end_timeから毎回計算して作られるので、
データ自体は「重複のない1アクティビティ1レコード」というシンプルな構造になっています。
(将来スマホ版に移植する場合も、このテーブル構造をほぼそのまま流用できます)

## 既知の制限(プロトタイプ版)

- タイマーが日をまたいで動作した場合、自動で2日分に分割して記録しますが、2日以上(24時間超)の連続計測には対応していません
- 日をまたいで分割された記録の片方だけを編集しても、もう片方には反映されません
- 集計はその日の合計時間のみ表示しています(月単位の集計やグラフ化は未実装)
